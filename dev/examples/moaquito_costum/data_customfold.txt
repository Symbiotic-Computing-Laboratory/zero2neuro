# Mosquito dataset — Scenario A (custom fold variant)
# Data format: per-location (year × epiweek × features) grid.
#
# Each training example is one (location, year) pair:
#   sequence length = N_EPIWEEKS timesteps
#   features        = n_input_features bio/env features
#   (year and epiweek are encoded as array axes, not feature values)
#
# Fold assignment is delegated to the Zero2Neuro framework:
#   - data_fold_split=group-by-file: each file gets a group number (= fold idx)
#   - generate_folds_by_group_numpy concatenates all files in the same group
#     along axis-0 -> (n_locs_in_fold * N_YEARS, N_EPIWEEKS, n_features)
#
# Workflow:
#   1. Run prepare_data_custom_fold.py  (generates one .pkl per trap location in ./dataset/)
#      The script prints the data_files block below — paste it in.
#   2. To control which location lands in which fold, use:
#        python prepare_data_custom_fold.py ... \
#          --data_location_folds "TrapA:0" "TrapB:1" "TrapC:0" ...
#      Locations not listed fall back to the seeded-random round-robin default.
